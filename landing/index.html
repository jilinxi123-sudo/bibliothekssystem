📚 Bibliothekssystem

Dies ist eine Software zur Bibliotheksverwaltung. Ein Gerät (in der Regel ein Windows-Computer) speichert alle Bücherdaten (im Folgenden „Hauptgerät" genannt); mehrere Geräte (Tablets, Handys usw.) im selben WLAN können sich per Netzwerk mit diesem Hauptgerät verbinden, um Bücherdaten zu erfassen und zu bearbeiten.

Voraussetzung dafür, dass die anderen Geräte genutzt werden können, ist, dass das Hauptgerät zur gleichen Zeit eingeschaltet und geöffnet ist.

Die Software benötigt fast nie eine Internetverbindung — mit einer Ausnahme: Sobald die ISBN eines Buches vorliegt, sucht das System automatisch bei der Deutschen Nationalbibliothek und bei Google Books nach Titel, Autor und weiteren Angaben. Die gefundenen Informationen (Titel, Autor, Verlag usw.) werden automatisch in das Formular eingetragen.

Installation auf dem Hauptgerät: ZIP herunterladen und entpacken (Ordner frei wählbar), dann darin einmal create_desktop_shortcut.bat doppelklicken — legt eine Desktop-Verknüpfung „Bibliothek" mit eigenem Icon an. Ab dann einfach dieses Icon verwenden, um Server zu starten und die Bibliothek zu öffnen. Kein separat installiertes Python nötig.
